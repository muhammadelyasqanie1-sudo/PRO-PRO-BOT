# ربات تلگرام – نسخهٔ حرفه‌ای

ربات عمومی با پنل مدیریت، ذخیره‌سازی SQLite، دو زبان (English / دری)، آمادهٔ اجرا روی Railway.

## امکانات

**شماره و OTP**
- ادمین شماره‌ها را دستی از پنل اضافه می‌کند: `Service | Country | +Number`.
- کاربران از دکمهٔ «دریافت شماره» شمارهٔ موجود را انتخاب می‌کنند؛ شماره به همان کاربر اختصاص داده می‌شود.
- در صورت تنظیم کلید API آگستِل، ربات پیامک‌های API را هر ۱۵ ثانیه بررسی می‌کند و OTP شمارهٔ اختصاص‌یافته را به همان کاربر می‌فرستد.
- قالب پاسخ API ممکن است با توجه به حساب/نسخهٔ پنل متفاوت باشد؛ اگر لاگ polling خطا داد باید مسیر و ساختار واقعی پاسخ مطابق مستندات حساب تنظیم شود.

**کاربران**
- انتخاب زبان، پروفایل، لینک دعوت اختصاصی و شمارش دعوت‌ها
- دکمه‌های پشتیبانی و کانال رسمی (لینک‌ها از پنل مدیریت تنظیم می‌شوند)

**پنل مدیریت** (`/admin` یا دکمهٔ «پنل مدیریت»)
- آمار: کل کاربران، فعال‌ها، مسدودشده‌ها، عضوهای امروز و ۷ روز اخیر، تعداد دعوت‌ها
- ارسال همگانی: هر نوع پیام (متن، عکس، ویدیو، فایل)، با تأیید قبل از ارسال و گزارش نهایی
- مسدود / آزاد کردن کاربر و دیدن اطلاعات کاربر
- عضویت اجباری در کانال‌ها (افزودن و حذف از داخل ربات)
- مدیریت ادمین‌ها (فقط مالک)
- حالت تعمیر (کاربران عادی پیام «در حال بروزرسانی» می‌بینند)
- تنظیم لینک پشتیبانی و کانال رسمی

## اجرا روی Railway

1. کد را در GitHub بگذارید و در Railway یک پروژه از روی آن بسازید.
2. در **Variables** این‌ها را بگذارید:
   - `BOT_TOKEN` : توکن از BotFather
   - `OWNER_ID` : آی‌دی عددی تلگرام شما (از ربات @userinfobot)
   - `DB_PATH` : `/data/bot.db`
   - `AUGESTEL_API_BASE` : `https://augestel.com/api/v1/iprn`
   - `AUGESTEL_API_KEY` : API key from your Augestel account (keep private)
   - `AUGESTEL_MESSAGES_PATH` : `/messages` unless your provider documentation specifies a different path
3. یک **Volume** بسازید و روی مسیر `/data` وصل کنید. بدون Volume با هر دیپلوی کاربران پاک می‌شوند.
4. Railway فایل `Procfile` را می‌خواند و ربات را با `python -m bot` اجرا می‌کند (نوع سرویس: worker).

## اجرا روی کامپیوتر

```bash
pip install -r requirements.txt
cp .env.example .env     # توکن و آی‌دی را در آن بنویسید
python -m bot
```

## عضویت اجباری

ربات باید در کانال **ادمین** باشد تا بتواند عضویت را بررسی کند. اگر ادمین نباشد، بررسی آن کانال رد می‌شود (تا کاربران قفل نشوند) و در لاگ هشدار می‌آید.

## ساختار

```
bot/
  app.py          ساخت برنامه و ثبت هندلرها
  guards.py       ثبت کاربر، مسدودی، حالت تعمیر، عضویت اجباری (قبل از همهٔ هندلرها)
  db.py           SQLite
  i18n.py         متن‌ها (برای زبان جدید یک دیکشنری اضافه کنید)
  handlers/       user.py ، admin.py ، router.py
tests/test_db.py  تست پایگاه‌داده
```

## نکتهٔ امنیتی

توکن را هرگز در کد یا GitHub ننویسید. اگر جایی فاش شده، در BotFather با `/revoke` توکن جدید بگیرید.
